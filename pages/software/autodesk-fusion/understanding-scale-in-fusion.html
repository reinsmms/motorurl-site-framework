Understanding Scale in Fusion

Fusion's Scale tool can be extremely useful, but it also creates some of the most confusing downstream problems in a parametric workflow. The biggest surprise is that scaling geometry does not always scale the underlying sketches, constraints, or design intent the way users expect.

Quick Warning

Recommended rule: Treat Scale as a finishing operation. If major edits are still expected, remove or suppress the Scale feature first, make changes, then apply Scale again as the final step.

The Biggest Surprise: Sketches Do Not Always Scale

One of the most confusing discoveries for many users is that scaling a body does not necessarily scale the sketch logic driving the model.

  • The body appears correctly scaled
  • The timeline still references the original sketches
  • Editing a sketch later may create unexpected recomputes or failures
Important distinction: Scaling geometry is not the same as redesigning the model at a different size.

Common Problems After Scaling

  • Fillets fail or change shape unexpectedly
  • Chamfers no longer look correct
  • Patterns behave inconsistently
  • Projected geometry loses references
  • Sketch edits cause large recomputes
  • Timeline operations become fragile
  • Mirrors and symmetry operations become unstable
  • Shell thicknesses scale differently than expected

Best-Practice Workflow

  1. Create sketches and dimensions first.
  2. Build the primary geometry.
  3. Add fillets, chamfers, mirrors, and patterns.
  4. Finalize the design.
  5. Apply Scale as one of the final operations.

If additional design work becomes necessary later:

  1. Suppress or remove the Scale feature.
  2. Edit the original geometry and sketches.
  3. Reapply Scale afterward if still needed.

Parametric Resizing vs Scale

Method What Changes Usually Safer?
Changing dimensions / parameters Underlying design logic Yes
Scale feature Resulting geometry Best used near the end of workflow

Key Takeaway

Fusion's Scale feature usually transforms resulting geometry rather than updating the underlying sketch intent. Because of this, Scale works best as a final-stage operation after most design work is complete.

Strong practical rule: If you need to make major edits after scaling, remove the Scale feature first, make the edits, then scale again afterward.
