Mirroring in Fusion

Mirroring in Fusion means copying geometry across a reference. The confusing part is that the reference changes depending on where you are working: inside a sketch you mirror across a line, while in 3D modeling you usually mirror across a plane or face.

Quick Answer

In a sketch, Fusion asks for a mirror line. Outside a sketch, Fusion usually asks for a mirror plane. The terms are different because sketch geometry is 2D, while bodies, components, and features exist in 3D space.

Sketch Mirror

Sketch Mirror is used while editing a sketch. It reflects selected sketch geometry across a line in that same sketch.

What the Mirror Line Is

The mirror line is the 2D reference line the sketch objects reflect across. Think of it like folding a piece of paper along a crease. The crease is the mirror line.

What Can Be Used as a Mirror Line

  • A construction line
  • A regular sketch line
  • A projected edge
  • An origin axis visible in the sketch

A dedicated construction centerline is usually the cleanest choice because it makes the relationship visible and easier to understand later.

Body, Feature, and Component Mirror

Outside a sketch, Fusion works in 3D. Instead of a mirror line, you usually select a plane, face, or construction plane as the mirror reference.

Common 3D Mirror Targets

  • Body mirror: mirrors an existing solid or surface body.
  • Feature mirror: mirrors a modeling operation from the timeline.
  • Component mirror: mirrors an entire component.

This is better when the shape already exists as 3D geometry and you want the mirrored copy to behave like a separate body, feature, or component.

Sketch Mirror vs Body / Feature Mirror

Type Reference Best For Main Risk
Sketch Mirror Mirror line Simple 2D sketch symmetry Can create extra sketch relationships that are harder to edit later
Body Mirror Plane, face, or construction plane Mirroring completed 3D geometry May create separate bodies that need to be joined or managed
Feature Mirror Plane, face, or construction plane Repeating a modeling operation parametrically Depends on feature order and timeline health
Component Mirror Plane, face, or construction plane Symmetrical assemblies or repeated parts Can add assembly complexity

When to Use Sketch Mirror

Use Sketch Mirror when the mirrored geometry is still part of the same 2D sketch and you want symmetry before creating a 3D feature.

Good Uses

  • Simple symmetrical profiles
  • Slots, ribs, or cutout outlines that are still easy to understand in one sketch
  • Early layout work where the sketch is not overloaded

Be Careful When

  • The sketch already has many constraints
  • You plan to rotate, stretch, or heavily edit the mirrored items later
  • You want the mirrored copy to become a separate body or independently editable object

When to Mirror a Body or Feature Instead

Mirror the body or feature when the shape is already 3D, when you want cleaner timeline control, or when sketch-level mirror relationships would make the sketch harder to edit.

Better Uses for 3D Mirror

  • Mirroring a completed bracket, tab, rib, clip, or support
  • Keeping the sketch simple and letting features do the repeated work
  • Creating geometry that may need to be joined, separated, or edited later
  • Avoiding large sketch patterns or mirrored sketch groups that slow down sketch solving

Why Sketch Mirrors Can Be Hard to Change Later

A common problem is mirroring geometry inside a sketch and later wanting to treat the mirrored result like separate 3D objects. That usually does not work the way expected because the mirror was created as part of the sketch, not as a separate body-level feature.

In that case, the mirrored items may still be tied to sketch constraints, symmetry relationships, dimensions, and the mirror line. Editing one side may affect the other side, or Fusion may resist movement because the sketch is still trying to preserve the mirrored relationship.

Rule of thumb: If you want mirrored geometry to remain part of one clean sketch, use Sketch Mirror. If you want the result to behave like actual 3D geometry that can be managed later, mirror the body, feature, or component instead.

Practical Workflow

  1. Create a simple sketch for the base profile.
  2. Use construction geometry for centerlines and references.
  3. Only use Sketch Mirror when the sketch will remain simple.
  4. Extrude or create the 3D geometry.
  5. If the mirrored shape needs separate control, use Body Mirror or Feature Mirror instead.
  6. Check the timeline so the mirror is easy to find and edit later.

Common Confusion

Fusion uses different mirror references depending on context. This is the same kind of reference issue that appears with angles, rotations, construction planes, and chamfers. Fusion is always asking: mirror across what?

  • Sketch mirror asks for a line because the sketch is already flat.
  • Body and feature mirror ask for a plane because the geometry exists in 3D space.
  • The mirror reference controls the result, so it should be chosen deliberately.

Key Takeaway

Sketch Mirror is best for simple 2D symmetry. Body, Feature, or Component Mirror is usually better when the shape already exists in 3D or needs to remain easier to manage later.
